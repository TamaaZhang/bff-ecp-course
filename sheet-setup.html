階段一準備：建立 Google Sheet 資料來源

    概覽

    做完這份說明，你會有：

    • 一份放會議室與預約資料的 Google 試算表
    • 一個給 BFF 呼叫的 Apps Script API（整門課只要部署這一次）
    • 填好的 bff/.env

    需要

    • 一個 Google 帳號（個人 Gmail 最保險；公司或學校帳號可能被管理者關掉 Apps Script）
    • 已安裝 Node.js 22.9 以上（產生通行碼會用到）
    • 學員起始包（裡面有 bff/.env.example）

    A. 建立試算表

    方法 1（建議）：用講師的範本

    1. 打開範本並建立副本 ↗
      按「建立副本」。範本已經含有資料和 Apps Script，副本會放在你自己的雲端硬碟。
    2. 接著做這一頁最下方的「兩種方法都要確認」，然後跳過 B，直接到 C. 產生通行碼。

    方法 2：自己建

    1. 打開 sheets.new 建立空白試算表，命名為「會議室預約」。
    2. 檔案 → 匯入 → 上傳，選起始包 sheet/ 資料夾裡的 會議室.csv，匯入位置選「插入新工作表」。
    3. 同樣方法匯入 預約.csv。
    4. 刪掉原本空白的「工作表1」。確認下方的工作表名稱剛好是 會議室 和 預約（一個字都不能差）。

    兩種方法都要確認

    • 檔案 → 設定 → 時區 是 (GMT+08:00) 台北。
    • 「預約」的開始、結束時間顯示成日期時間（例如 2026/11/24 9:00:00）。如果顯示成小數，選取那兩欄，格式 → 數值 → 日期時間。

    範例預約用了 =TODAY() 公式，所以每天打開都會是「今天」和「明天」的預約，方便練習。

    B. 貼上 Apps Script

    用方法 1（範本）的人跳過這一步：範本已經有 Apps Script 了。

    1. 在試算表選 擴充功能 → Apps Script。
    2. 刪掉編輯器裡原本的內容，把起始包的 sheet/Code.gs 整份貼上，按儲存（磁碟片圖示）。

    C. 產生通行碼

    通行碼是 BFF 和 Apps Script 之間的「暗號」：BFF 呼叫時要帶上，Apps Script 對了才回資料。

    1. 在你自己的終端機（Windows：PowerShell；Mac：終端機）執行下面這行，會印出一長串亂數，這就是你的通行碼：
      node -e "console.log(crypto.randomUUID() + crypto.randomUUID())"

      不要請 AI 幫你執行這行：AI 執行的指令，輸出會留在對話紀錄裡。

    2. 在 Apps Script 左側按「專案設定」（齒輪）→ 最下方「指令碼屬性」→「新增指令碼屬性」：
      屬性BFF_TOKEN
      值剛剛那串通行碼
      按「儲存指令碼屬性」。

    D. 部署成網頁 API

    1. Apps Script 右上角 部署 → 新增部署作業。
    2. 左邊齒輪選「網頁應用程式」。
    3. 執行身分：我；誰可以存取：所有人。
    4. 按「部署」。第一次會要求授權：選你的帳號 → 看到「Google 尚未驗證這個應用程式」時按「進階」→「前往（不安全）」→「允許」。
      這是因為這支程式是你自己的，還沒送 Google 審核；它只會讀寫你這份試算表的「會議室」「預約」兩張工作表。
    5. 複製「網頁應用程式」網址（結尾是 /exec）。

    「所有人」的意思是：知道網址的人都能呼叫。所以才需要通行碼：沒有通行碼的呼叫，只會得到 unauthorized。

    E. 填寫 bff/.env

    1. 把 bff/.env.example 複製一份，改名為 bff/.env（同一個資料夾）。
    2. 填入（等號後面直接接值，不用加引號）：
      這一行填什麼
      SHEET_API_URL=剛剛的 /exec 網址
      SHEET_API_TOKEN=你的通行碼
    3. 存檔。

    哪些可以告訴 AI

    項目可以告訴 AI 嗎
    網頁應用程式網址可以（沒有通行碼也讀不到資料）
    工作表名稱、欄位名稱可以
    通行碼不可以，只寫在 bff/.env

    做完了

    在起始包資料夾用 Claude Code 輸入 /bff-step1-sheet-query（Codex：貼上 提示詞/STEP1_查詢.md），開始階段一。

    之後改了 Code.gs 怎麼辦

    改完儲存後，要 部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署。

    不這樣做的話，網址背後跑的還是舊版程式。網址不會變，.env 不用改。

    常見問題

    看到原因
    DATA-503、source_auth_failed.env 的通行碼和指令碼屬性不一樣；或「誰可以存取」不是「所有人」
    DATA-503、source_unavailable網址貼錯、網路不通，或 Google 暫時沒回應（稍等再試）
    DATA-502、source_bad_response工作表名稱或第一列欄位名稱和範例不同；或改了 Code.gs 沒部署新版本
    查得到會議室，預約卻是空的試算表時區不是台北，或時間欄是文字不是日期時間
