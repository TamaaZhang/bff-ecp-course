概覽

開始階段一之前，先把電腦準備好。從公司 OneDrive 下載兩個壓縮檔之後，照這一頁做完就可以上課。

段落做什麼什麼時候用到
A. 解壓縮把學員起始包、本地 ECP 教材包放到電腦上全部
B. 安裝 Node.jsBFF 用它來執行階段一起
C. 安裝 Claude Code請 AI 寫程式階段一起
D. 啟動本地 ECP安裝 Docker Desktop，第一次啟動 ECP、登入階段二起
E. 確認三件事都正常上課前

需要

  • Windows 10／11（Mac 也可以，但本地 ECP 在 Mac 上還沒有實機測過）
  • 記憶體 8GB 以上、硬碟空間 5GB 以上
  • 可以安裝軟體的權限（公司電腦可能要請 IT 開）
  • Claude 付費帳號（Pro 以上）

A. 解壓縮

  1. 在電腦上建一個資料夾放課程檔案，例如 C:\bff-course。路徑不要有空白，最好也不要放在 OneDrive 同步的資料夾裡。
  2. 把兩個壓縮檔都解壓縮到這個資料夾（Windows：在壓縮檔上按右鍵 →「解壓縮全部」；Mac：連按兩下）：
    壓縮檔解開後用途
    學員起始包裡面有 AGENTS.md、bff、web、提示詞 等你的專案，AI 在這裡寫程式
    本地 ECP 教材包裡面有 啟動ECP.cmd、初始密碼.txt、ecp-teaching-images.tar 等在自己電腦上跑一套 ECP

一定要先解壓縮。直接在壓縮檔裡面連按兩下打開的檔案，程式會找不到其他檔案。

B. 安裝 Node.js

  1. 打開 https://nodejs.org/，下載 LTS 版（22 或更新）。
  2. 執行安裝程式（Windows 是 .msi、Mac 是 .pkg），選項都用預設，一直按「Next」到完成。
  3. 重新打開一個終端機（Windows：開始功能表搜尋 PowerShell；Mac：終端機），輸入：
    node --version
    看到 v22.9.0 或更大的數字（例如 v22.12.0、v24.1.0）就對了。

出現「無法辨識 node」或 command not found：通常是終端機在安裝前就開著。把它關掉重開；還是不行就重新開機。

C. 安裝 Claude Code

  1. 打開 https://claude.ai/download，下載並安裝 Claude 桌面 App。
  2. 打開 App，用你的 Claude 帳號登入。
  3. 切到 Code 分頁，選擇 A 解開的學員起始包資料夾。App 如果提示要安裝其他元件（例如 Git），照提示安裝。
  4. 在對話框輸入「這個資料夾是做什麼的？」。AI 能說出這是會議室預約看板的課程專案，就設定好了。

用 Codex 的人：照 Codex 的說明安裝，打開同一個學員起始包資料夾。之後每個步驟改成貼上 提示詞/ 裡對應的檔案。

D. 啟動本地 ECP

本地 ECP 跑在 Docker 裡：不用安裝資料庫，也不會動到電腦上其他的程式。

1. 安裝 Docker Desktop

  1. 打開 https://www.docker.com/products/docker-desktop/，下載並安裝 Docker Desktop（Mac 要選對晶片：Apple Silicon 或 Intel）。
  2. Windows 安裝時如果要求安裝或更新 WSL，照提示做，完成後重新開機。
  3. 打開 Docker Desktop，等左下角顯示 Engine running。第一次打開會問要不要登入，可以跳過。

2. 第一次啟動 ECP

  1. Docker Desktop 保持開著。
  2. Windows：打開 ECP 教材包資料夾，連按兩下 啟動ECP.cmd。
    Mac：打開終端機，輸入 cd （後面有一個空白），把 ECP 教材包資料夾拖進終端機視窗，按 Enter，再輸入：
    bash ecp.sh start
  3. 第一次會載入映像檔、建立資料庫，大約 3～5 分鐘，視窗會一直跑文字，等它跑完。
  4. 完成後瀏覽器會自動打開 http://127.0.0.1:22821/aipower/（沒有自動打開就自己貼上這個網址）。
  5. 登入名稱填 administrator，密碼在 ECP 教材包資料夾的 初始密碼.txt。看到 ECP 首頁就成功了。

密碼連錯約 3 次，ECP 會把帳號鎖 30 分鐘。登不進去時，先打開 初始密碼.txt 重新複製，不要一直試。

平常使用

要做的事WindowsMac
啟動（先開 Docker Desktop）啟動ECP.cmdbash ecp.sh start
停止（資料會保留）停止ECP.cmdbash ecp.sh stop

ECP 很吃記憶體，不上課時可以停止，資料會留著。停止或重開電腦都不會遺失資料，只有「重設」才會清空。

E. 確認

上課前確認這三件事都正常：

#操作應該看到
1終端機輸入 node --versionv22.9.0 或更大
2Claude 桌面 App → Code 分頁，打開學員起始包AI 能回答你的問題
3啟動 ECP，打開 http://127.0.0.1:22821/aipower/能用 administrator 登入

都正常就可以開始 階段一：Sheet 版。

常見問題

看到原因
終端機說找不到 node終端機在安裝前就開著。關掉重開；還不行就重新開機
node --version 小於 22.9電腦上原本有舊版。到 nodejs.org 重新安裝 LTS 版
啟動 ECP 時說找不到 DockerDocker Desktop 沒開，或還沒啟動完成。等左下角顯示 Engine running 再執行
啟動失敗，訊息提到 22821這個連接埠被其他程式佔用（例如另一套 ECP 還開著）。先關掉那個程式
等了 10 分鐘還沒好在 ECP 教材包資料夾打開終端機，執行 docker compose logs ecp，把最後幾行給講師看
Docker Desktop 說要開虛擬化（virtualization）電腦的 BIOS 沒開虛擬化，請 IT 協助
ECP 教材包資料夾裡多了一個 .env第一次啟動時自動產生，是這台電腦專用的資料庫密碼。不要刪；刪了只能重設 ECP
